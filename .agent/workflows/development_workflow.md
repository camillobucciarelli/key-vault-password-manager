# Development Workflow

1. Understand feature requirements.
2. Update/create Domain layer (Entities, Usecases, Repository interfaces).
3. Update/create Data layer (DTOs/Models, Datasources, Repository Implementations).
4. Update/create Presentation layer (BLoC events & states, Pages, Widgets).
5. Run `flutter analyze` and `flutter test`.
