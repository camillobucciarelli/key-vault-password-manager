# 007 — Plan

## Approach

The design project ships pre-rendered PNGs under
`design_handoff_keyvault_restyle/icons/`. Two options:

1. **Copy them** — fastest, zero tooling.
2. **Regenerate from the SVG masters** in `specs/_design/` at 4× and downsample.

Take (1) for the ship, and keep (2) as the reproducible path: the SVG masters are
already in the repo, so a `tool/build_icons.sh` one-liner over `rsvg-convert` or
`resvg` regenerates everything if a size ever changes. Write the script — it is
five lines and removes the "where did this PNG come from" question — but do not
build a Dart tool for it.

## Monochrome derivation

`keyvault-mark-foreground.svg` with every `stroke` and `fill` replaced by
`#ffffff`:

```
sed -E 's/(stroke|fill)="#[0-9a-f]{6}"/\1="#ffffff"/g' \
  icons/keyvault-mark-foreground.svg > icons/keyvault-mark-monochrome.svg
```

(`fill="none"` must survive — the sed above only matches hex values, so it does.)

## Risks

| Risk | Mitigation |
| --- | --- |
| Downsampling to 16 px muddies the notches | Render at 4× (64 px) then Lanczos-downsample; visual check at 100 % zoom in the toolbar |
| `remove_alpha_ios` fails because the source has alpha | The source PNG is full-bleed `#ffe1d0` — no alpha by construction; assert with `identify -format '%[channels]'` |
| An OEM mask crops the ink | Already handled by the 0.75 scale; verify on circle/squircle/rounded-square |
| Deleting the old logos breaks a stale reference | Sweep with `rg` before deleting |
