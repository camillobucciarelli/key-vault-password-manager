# Triage Labels

These labels apply only to ordinary issues. Issues carrying `spec` are generated roadmap mirrors and stay outside triage.

| Canonical role    | Repository label  | Meaning                                  |
| ----------------- | ----------------- | ---------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer must evaluate the issue       |
| `needs-info`      | `needs-info`      | Waiting for reporter information         |
| `ready-for-agent` | `ready-for-agent` | Fully specified and agent-ready          |
| `ready-for-human` | `ready-for-human` | Requires human implementation            |
| `wontfix`         | `wontfix`         | Will not be actioned                     |

Category roles use existing `bug` and `enhancement` labels. Every triaged ordinary issue should carry one category label and one state label.
